# 6주차 실습 기록

## 프로젝트 개요

**장르:** 빙판 위 스네이크 퍼즐 게임  
**제목:** Ice Snake Puzzle  
**개발 환경:** Python 3, Pygame  
**맵 제작 방식:** 수작업

---

## 사용한 에셋

### 이미지 (sprites 폴더)

| 파일명 | 용도 |
|---|---|
| `ice.png` | 바닥 타일 |
| `wall.png` | 벽 |
| `rock.png` | 바위 (이동 정지 기준) |
| `portal_closed.png` | 출구 (잠김) |
| `portal_open.png` | 출구 (열림) |
| `spike.png` | 가시 (즉사 오브젝트) |
| `key.png` | 열쇠 |

> 이미지가 없을 경우 fallback 함수로 도형을 직접 그려 대체합니다.  
> 열쇠는 이미지 대신 `draw_key()` 함수로 코드에서 직접 그립니다.

### 사운드

- 현재 미사용 (추후 적용 예정)

---

## 핵심 게임 규칙

1. 방향키를 누르면 플레이어가 **벽 또는 바위에 닿을 때까지 미끄러집니다.**
2. 자기 몸에 닿으면 **즉사** 처리됩니다.
3. 가시에 닿으면 **즉사** 처리됩니다.
4. **열쇠를 먼저 획득해야** 출구가 열립니다.
5. 열린 출구에 진입하면 **스테이지 클리어**입니다.

---

## 게임 구성

| 구분 | 내용 |
|---|---|
| 튜토리얼 | 3단계 (기본 조작, 열쇠, 자기 몸 충돌) |
| 메인 스테이지 | 총 20스테이지 |
| 난이도 구간 | 1~5: 기본 / 6~10: 경로 판단 / 11~15: 이동 순서·정지 위치 / 16~20: 가시 + 좁은 경로 복합 |

---

## 사용한 AI 프롬프트 (요약)

1. 기존 로그라이크/뱀서류 게임에서 독창적인 아이디어를 넣는 방법 질문
2. 게임 방향을 마리오식 블록 퍼즐로 바꾸는 아이디어 요청
3. 스네이크 기반 빙판 퍼즐 게임으로 재설계 요청
4. 방향키를 누르면 벽·바위 전까지 미끄러지는 구조의 전체 코드 작성 요청
5. 튜토리얼·메뉴·20스테이지 구성·후반 난이도 상승 구조 추가 요청
6. 스프라이트 이미지 적용 방식 요청
7. 이미지 좌표 재조정, 잘림 문제 수정, 열쇠를 코드로 직접 그리도록 변경 요청
8. 플레이어를 이미지 대신 파란 네모로 변경하고 화면 크기 확대 요청

---

## AI 답변 활용 내역

### 도움이 된 것

- 게임 방향을 여러 번 바꾸면서도 핵심 규칙을 정리할 수 있었음
- 스네이크를 단순 먹기 게임이 아니라 퍼즐 구조로 전환하는 아이디어를 얻음
- "방향키를 누르면 끝까지 미끄러진다"는 핵심 규칙을 코드로 구현하는 데 도움이 됨
- 튜토리얼·메뉴·클리어 화면·20스테이지 구조를 한 번에 정리할 수 있었음
- 스프라이트를 잘라 쓰는 방식과 좌표 조정 방법을 이해하는 데 도움이 됨
- 열쇠 이미지를 코드로 직접 그려서 에셋 문제를 우회하는 방법이 유용했음

### 수정하거나 버린 것

- 처음에는 로그라이크/뱀서류 방향으로 진행했지만 최종 폐기
- 마리오식 블록 퍼즐 아이디어도 검토했으나 스네이크 빙판 퍼즐로 변경
- 플레이어 머리 이미지를 사용하는 방식은 어색해서 파란 네모로 수정
- 열쇠 이미지는 시트에서 잘려 보여 코드로 직접 그리도록 교체
- 일부 스프라이트 좌표는 AI 제안값을 그대로 쓰지 않고 여러 번 직접 수정
- 초반 맵이 너무 쉬워서 20스테이지 구조로 재구성하고 후반 난이도를 보완

---

## 적용 결과

### 잘 된 것

- 빙판에서 미끄러지는 퍼즐 규칙이 의도대로 구현됨
- 자기 몸 충돌 규칙이 퍼즐성과 긴장감을 높여줌
- 튜토리얼과 메뉴를 추가해 조작 방식 설명이 명확해짐
- 스프라이트 적용으로 기본 도형 버전보다 화면이 훨씬 보기 좋아짐
- 플레이어를 파란 네모로 바꾸면서 가독성이 좋아짐

### 어려웠던 것

- 스프라이트 좌표를 정확하게 맞추는 과정이 까다로웠음
- 이미지가 칸에 딱 맞지 않아 잘리거나 밀려 보이는 문제가 있었음
- 열쇠처럼 일부 에셋은 그대로 사용하기 어려웠음
- 스테이지별 난이도 균형을 맞추는 것이 생각보다 시간이 걸렸음
