# 6주차 실습 기록

## 사용한 에셋
- 이미지:
  - `sheet.png` (직접 제작한 스프라이트 시트)
  - 구성: 얼음 타일, 벽, 바위, 포탈(닫힘/열림), 가시
- 사운드:
  - 사용하지 않음(사용 예정)

## 사용한 AI 프롬프트 (요약)
1. 기존 로그라이크/뱀서류 게임에서 독창적인 아이디어를 
넣는 방법 질문
2. 게임 방향을 마리오식 블록 퍼즐로 바꾸는 아이디어 요청
3. 다시 방향을 바꿔 스네이크 기반 빙판 퍼즐 게임으로 
재설계 요청
4. 빙판 위에서 한 번 이동하면 벽/바위 전까지 
미끄러지는 구조의 전체 코드 작성 요청
5. 튜토리얼, 메뉴, 20스테이지 구성, 후반 난이도 상승 
구조 추가 요청
6. 스프라이트 시트 기반 이미지 적용 방식 요청
7. 이미지 좌표 재조정, 잘림 문제 수정, 열쇠를 코드로 
직접 그리도록 변경 요청
8. 플레이어를 이미지 대신 파란 네모로 변경하고 화면 크기 확대 요청

## AI 답변에서 도움이 된 것
- 게임 방향을 여러 번 바꾸면서도 핵심 규칙을 정리할 수 있었음
- 스네이크를 단순 먹기 게임이 아니라 퍼즐 구조로 바꾸는 아이디어를 얻음
- “방향키를 누르면 끝까지 미끄러진다”는 핵심 규칙을 코드로 구현할 수 있었음
- 튜토리얼, 메뉴, 클리어 화면, 20스테이지 구조를 한 번에 정리할 수 있었음
- 스프라이트 시트를 잘라 쓰는 방식과 좌표 조정 방식을 이해하는 데 도움이 되었음
- 열쇠 이미지를 코드로 직접 그려서 에셋 문제를 우회하는 방법이 유용했음

## AI 답변을 수정하거나 버린 것
- 처음에는 로그라이크/뱀서류 방향으로 진행했지만 최종적으로 폐기함
- 마리오식 블록 퍼즐 아이디어도 검토했으나 스네이크 빙판 퍼즐로 변경함
- 플레이어 머리 이미지를 쓰는 방식은 어색해서 버리고 파란 네모로 수정함
- 열쇠 이미지는 시트에서 잘려 보여서 사용하지 않고 코드로 직접 그리도록 바꿈
- 일부 스프라이트 좌표는 AI가 제안한 값을 그대로 쓰지 않고 여러 번 수정함
- 맵이 너무 쉬워서 20스테이지 구조와 후반 난이도 상승 방향으로 보완함

## 적용 결과
- 잘 된 것:
  - 빙판에서 미끄러지는 퍼즐 규칙이 잘 구현됨
  - 자기 몸에 닿으면 죽는 규칙이 퍼즐성과 긴장감을 높여줌
  - 튜토리얼과 메뉴를 넣어서 조작 방식을 설명하기 쉬워짐
  - 스프라이트 시트 적용으로 기본 도형 버전보다 게임 화면이 훨씬 보기 좋아짐
  - 플레이어를 파란 네모로 바꾸면서 가독성이 좋아짐

- 어려웠던 것:
  - 스프라이트 시트 좌표를 정확하게 맞추는 과정이 어려웠음
  - 이미지가 칸에 딱 맞지 않아 잘리거나 밀려 보이는 문제가 있었음
  - 열쇠 이미지처럼 일부 에셋은 그대로 쓰기 어려웠음
  - 스테이지 난이도를 맞추는 것이 생각보다 까다로웠음

- 다음에 시도할 것:
  - 스프라이트 좌표를 더 정밀하게 보정
  - 맵 20개 난이도를 다시 조정
  - 포탈, 열쇠, 가시 등 주요 오브젝트의 시각 효과 개선
  - 플레이어 이동/클리어 연출 추가
  - 필요하면 얼음 타일 반복감을 줄이기 위한 추가 배경 타일 제작
